[center][size=5][b]TechRankExpander[/b][/size]
[i]Expanded tech ranks and configurable progression for Farthest Frontier[/i][/center]

[size=4][b]Overview[/b][/size]
TechRankExpander expands the tech tree beyond the vanilla rank limits and gives you more control over the game's progression systems.

[list]
[*]Most technologies can be researched up to [b]20 ranks[/b] instead of the vanilla 1–3.
[*]Knowledge Point generation can be sped up with a configurable multiplier.
[*]Villager carry capacity and the Production Management work-speed bonus are configurable.
[*]Prerequisites unlock at rank 1 instead of requiring full research.
[*]Tech-linked buildings unlock at rank 1.
[*]Deep Wells gains a configurable water bonus per rank, with tooltip support in multiple UI languages.
[*]Reset Tech Tree and Allot All Techs can be applied on load.
[/list]

[size=4][b]Default settings[/b][/size]
[list]
[*]KP speed multiplier: [b]5x[/b]
[*]Carry capacity multiplier: [b]3x[/b]
[*]Work-speed bonus: [b]+1% per Production Management rank[/b]
[*]Deep Wells water volume per rank: [b]+50[/b]
[*]Reset Tech Tree: [b]off[/b]
[*]Allot All Techs: [b]off[/b]
[/list]

[size=4][b]Safe caps[/b][/size]
Some technologies use percentage-based effects that break if their rank cap is raised too far. TechRankExpander enforces safe limits automatically to protect game logic.

[b]Hardcoded (not configurable):[/b]
[list]
[*][b]Civic Inspections[/b] — cap 3 (rank 4+ gives negative firefighter work time → workers freeze)
[*][b]Sheet Composting[/b] — cap 3 (rank 4+ gives negative compost work time → Compost Yard breaks)
[*][b]Hygiene[/b] — cap 4 (game uses Clamp01 internally; rank 5+ is redundant)
[/list]

[b]Configurable with runtime clamp:[/b]
[list]
[*][b]Favored Nation[/b] — default 1, hard max 9 (rank 10 = 0 gold from bazaar; rank 11+ = negative prices)
[*][b]Sustainable Farming[/b] — default 3, hard max 3 (rank 4 = 0% fertility loss; rank 5+ reverses fertility → farms restore indefinitely)
[/list]

[b]Configurable (no hard clamp, safe by default):[/b]
[list]
[*][b]Horse Barding[/b] — cap 6 (−15% cavalry speed/rank; game clamps penalty to <100% so rank 7+ is silently ignored — horses never freeze; +30% health/rank is uncapped)
[*]Steel Tools, Military Logistics, Production Logistics, Metallurgy — cap 9 (−10%/rank; rank 10 = instant craft)
[*]Venting Chambers — cap 6 (−15%/rank; rank 7 = instant craft)
[*]Spring Pole Lathe, Stiff-Blade Saw, Stonecutting — cap 4 (−20%/rank; rank 5 = instant)
[*]Adjustable Shoe Lasts — cap 3 (−25%/rank; rank 4 = instant craft)
[*]Masonry — cap 15 (compound −25% of current bricks per rank; stabilises at 1–2 bricks)
[*]Printing Press — cap 1 (−50%/rank; rank 2 = instant craft)
[/list]

[b]Note on Masonry:[/b] the game applies a [i]compound[/i] reduction (each rank reduces the current brick count by 25%, not the original). This was previously documented incorrectly as linear. Cap raised from 5 to 15.

[b]Work-time caps (Steel Tools etc.):[/b] the game internally clamps work units to 0 minimum — they do not go negative. Caps are set to prevent instant (0-time) production, not to prevent negative values.

[size=4][b]Configuration[/b][/size]
After the first game launch, edit:
[code]<game folder>\UserData\TechRankExpander.cfg[/code]

Key entries include:
[code]
KP_Speed_Multiplier = 5.0
Carry_Capacity_Multiplier = 3.0
Work_Speed_Per_Rank = 0.01
Deep_Wells_Water_Volume_Per_Rank = 50
Reset_Tech_Tree = false
Allot_All_Techs = false
KP_Hotkey = F8
KP_Hotkey_Amount = 1

Ranks_Favored_Nation = 1       # hard clamped to max 9 in code
Ranks_Sustainable_Farming = 4  # hard clamped to max 4 in code
Ranks_Steel_Tools = 9
Ranks_Masonry = 15             # compound reduction — safe up to ~20
Ranks_Stonecutting = 4
[/code]

[b]Allot_All_Techs[/b] fills each tech to its configured cap on every load until you turn it off manually. [b]Reset_Tech_Tree[/b] still works as a one-time load option.

[b]Note on language:[/b] mod tooltips and config descriptions are shown in the game's current UI language. If you change the language in the game settings, [b]restart the game[/b] for the mod text to update.

v2.2.2 — Forging fix + Horse Barding safe cap

Forging ("Unlock Foundry") is now treated as an unlock-only technology
and removed from the rank expansion list. It previously appeared as
0/20 in the tech tree despite having no repeatable per-rank bonus.
Old Ranks_Forging entries in existing cfg files are removed automatically
on first load.

Horse Barding cap lowered from 20 to 6. Each rank applies −15% cavalry
speed via GE_MountedSoldierModify. The game internally clamps the total
movement penalty to <100%, so ranks 7–20 were silently ignored and wasted
research points. Cap 6 = −90% speed (near-stationary cavalry, maximum
meaningful effect). The +30% health per rank has no upper limit and
continues to apply at any cap setting.

v2.2.1 — Fix unlock-only tech cap bypass via cfg

Unlock-only technologies (those that only unlock a building, resource,
or unit at rank 1 with no repeatable bonus) are now hardcoded to cap=1
regardless of the UserData/TechRankExpander.cfg file contents.

Previously, if the cfg file was written by an earlier mod version with
cap=20 for these techs (Animal Husbandry, Cavalry, Forestry, etc.), the
old values persisted and allowed researching beyond rank 1 — which had
no gameplay effect but looked wrong in the UI (e.g. "0/20" instead of
"0/1"). These techs no longer appear in the cfg file at all; their cap
is always exactly 1.

Full list of affected techs: Animal Husbandry, Commerce Negotiations,
Coal-Fired Stoves, Intensive Animal Farming, Siege Warfare, Conscription,
Convenience Tax, Prohibition, Brigandine Armor, Economic Power, Beacon of
Culture, Gates of Valor, Guilds, Pharmacy, Citadels, Canning, Caseiculture,
Trade Center, Bookbinding, Hospitalization, School of Thought, Cavalry,
Reinforced Plating, Tools of War, Grain Crops, Arrow Loops, Market Forces,
Nursing, Stone Battlements, Forestry, Battlement Fortifications,
Wonders of the Frontier.

v2.0.0 — Full update for Farthest Frontier v1.9.4

Breaking change: the game's ActivateTechOrRank method gained a new
knowledgePointCost parameter in v1.9.4. The previous mod version would crash
on load due to the Harmony patch signature mismatch. Fixed.

Added 40+ new technologies introduced in v1.9.4 to the rank-expansion system:
Rodent-Proofing, Animal Husbandry, Commerce Negotiations, Coal-Fired Stoves,
Intensive Animal Farming, Siege Warfare, Conscription, Convenience Tax,
Prohibition, Brigandine Armor, Economic Power, Beacon of Culture, Gates of
Valor, Guilds, Pharmacy, Citadels, Canning, Blast Furnace, Quarry, Woodworking,
Caseiculture, Brewing, Barrel-Making, Trade Center, Bookbinding, Hospitalization,
School of Thought, Cavalry, Reinforced Plating, Tools of War, Glass Blowing,
Grain Crops, Arrow Loops, Arms Production, Smithing, Forging, Market Forces,
Paper Press, Nursing, Stone Battlements, Mining, Forestry, Battlement
Fortifications, Wonders of the Frontier.

Work-time techs (Blast Furnace, Quarry, Woodworking, Brewing, Barrel-Making,
Bookbinding, Glass Blowing, Arms Production, Smithing, Forging, Paper Press,
Mining) default to conservative caps (4 or 9) to preserve nonzero work time.
All others default to 20. Adjust in UserData/TechRankExpander.cfg.

v1.9.2 — Bug fixes & protection mechanism

Fixed wrong caps (found by decompiling Assembly-CSharp.dll):
• Masonry cap raised 5 → 15: reduction is COMPOUND (−25% of current bricks per
  rank, not original). Previous cap was based on incorrect linear assumption.
• Stonecutting cap lowered 5 → 4: rank 5 = instant mining (0 work units). Cap
  at 4 keeps at least 20% work time.
• Sustainable Farming default raised 3 → 4, hard runtime clamp at max 4.
  Rank 4 = 0% fertility loss (safe). Rank 5+ = farms restore fertility (broken).
• All work-time comments corrected: game clamps to 0 (instant), not negative.

Protection mechanism added:
• Runtime guard on HappinessManager.GetWorkRateMultiplier(Villager) ensures
  occupation work rates never go negative (workers can never freeze due to
  misconfigured tech bonuses).
• Runtime clamp for Sustainable Farming with a logged warning.

v1.9.1 — Bug fixes
• Livestock barn capacity no longer compounds on repeated map reloads.
• KP refund/cost counters now reset at load start, not just load end.
